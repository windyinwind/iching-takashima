# 起卦法

四种方法，全部为确定性运算。同一输入必得同一结果。

| 方法 | 参数 | 所本 | 动爻 |
|---|---|---|---|
| 略筮法（默认） | `--seed` 或 `--piles` | 《増補高島易断》筮儀，高島呑象常用 | 恒一爻 |
| 大衍筮法 | `--seed --variant dayan` | 《周易·系辞上》，朱熹《周易本义·筮仪》 | 0–6 爻 |
| 数字起卦 | `--numbers` | 《梅花易数》报数起卦 | 恒一爻 |
| 时间起卦 | `--at` | 《梅花易数》年月日时起卦 | 恒一爻 |

## 为什么要确定性

这是本项目最核心的技术性质，也是唯一无法用 AI 替代的部分。

大语言模型直接答卦会漂移——同一个问题问两次可能得到不同答案。
用户要的是「确定的输出」，恰是自己那个 AI 给不了的东西。

自检 `tests/test_engine.py`（`TestDeterminismAndChain`）对每种方法重复起卦，结果完全一致。

## 先天八卦数

乾 1、兑 2、离 3、震 4、巽 5、坎 6、艮 7、坤 8。四种方法都用此表把数译成卦。

## 一、略筮法（三变筮）

高島呑象自述：「今世所现行之筮法者，大别而有本筮（十八变）中筮（六变）略筮（三变）之三种……
今吾辈之常用《易》，三变之略筮法最为适当。」（《増補高島易断》筮儀）

### 手续

1. 五十本筮竹取一本不用，以象太极；余四十九本。
2. 至诚默念，随手分为二（象两仪）。
3. 右手一堆置案上，自中取一本挟于左手小指（挂一，象三才）。
4. 左手之策八本八本数之（二本一数，四数为八，象四时），余 0–7 本，
   加小指一本，得数 1–8，按先天数定卦。
5. **第一变定内卦（下卦）**，合策重分，**第二变定外卦（上卦）**。
   高島先装内卦、后装外卦：「《易》，逆数也」，自下而上。
6. 第三变同前，但左手之策**六本六本**数之，余数加一，得 1–6：
   1 初爻、2 二爻 … 6 上爻，为动爻。

### 算式

```
得数₁ = 左手根数₁ mod 8 + 1   → 内卦（下卦）
得数₂ = 左手根数₂ mod 8 + 1   → 外卦（上卦）
得数₃ = 左手根数₃ mod 6 + 1   → 动爻（1 = 初爻）
```

左手根数在 1–48 之间（四十九本分二，右手至少留一本以挂一）。
动爻若为阳标老阳 9，若为阴标老阴 6；余五爻为少阳 7、少阴 8。

### 两种输入

- `--seed "当下所念"`：以 SHA-256 摘要流代替手分筮竹，三个数分别取作三变的左手根数。
- `--piles 21 22 16`：用户亲手分筮竹，报三变时左手的根数。

### 书中例证（均已写入自检）

筮儀所举装卦之例：

| 第一变 | 第二变 | 卦 |
|---|---|---|
| 一本（乾，下） | 五本（巽，上） | 风天小畜 |
| 二本（兑） | 六本（坎） | 水泽节 |
| 三本（离） | 七本（艮） | 山火贲 |
| 四本（震） | 八本（坤） | 地雷复 |

占例：

- 福原実荣转冲绳县知事，筮得「蒙之涣」，断辞据六五「童蒙，吉」。
  `--piles 21 22 16`：21→坎（内），22→艮（外），16→五爻。
- 左右田金作问入社，筮得「需之井」，断辞引初九「需于郊」。
  `--piles 8 13 6`：8→乾（内），13→坎（外），6→初爻。

### 不收录的部分

筮儀列举本筮（十八变）、中筮（六变）、略筮（三变）三种，但只详述略筮手续，
中筮法未载其法。坊间中筮各派（如真势流）手续不一，本工具不据以杜撰。

网传「男用左手、女用右手」取动爻之说，号称高島不传之法，书中筮儀未载，本工具不采用。
`shaoban` 是本工具旧版对略筮法的误称（旧版算法亦非书中手续），现作为 `lueshi` 的别名保留。

## 二、大衍筮法（十八变）

「大衍之数五十，其用四十有九。分而为二以象两，挂一以象三，揲之以四以象四时，归奇于扐以象闰。」

每一变：

1. 将 n 本分为左右两堆。
2. 右堆取一本挂于指间（挂一）。
3. 左右各四本四本揲之，各余 1–4（整除则余 4）。
4. 挂一 + 左余 + 右余 为本变所去。第一变恒去 5 或 9，第二、三变恒去 4 或 8。

三变之后余策必为 36 / 32 / 28 / 24，除四得：

| 余策 | 爻值 | 名称 | 阴阳 | 动静 | 传统概率 |
|---|---|---|---|---|---|
| 24 | 6 | 老阴 | 阴 | 动 | 1/16 |
| 28 | 7 | 少阳 | 阳 | 静 | 5/16 |
| 32 | 8 | 少阴 | 阴 | 静 | 7/16 |
| 36 | 9 | 老阳 | 阳 | 动 | 3/16 |

自初爻起，共六爻、十八变。动爻数不定；变卦由全部动爻一并变出。
自检以精确枚举验证本实现的爻值分布与传统概率相差不超过 0.02。

## 三、数字起卦（梅花易数）

用户心中默念一事，报两个或三个正整数。

```
上卦 = 数一 mod 8
下卦 = 数二 mod 8
动爻 = 诸数之和 mod 6
```

余 0 时卦取 8（坤），爻取 6（上爻）。例：7、13 → 7 艮上，13 mod 8 = 5 巽下，20 mod 6 = 2 → 山风蛊，动九二。

系统不接收占问事项。用户报的数字不带语义，意图完全在用户自己心里——这是合规设计，见 `compliance.md`。

## 四、时间起卦（梅花易数年月日时）

```
年 = 农历年的年支数（子 1、丑 2 … 亥 12）
月 = 农历月数（闰月按本月之数）
日 = 农历日数
时 = 时支数（子 1 … 亥 12）

上卦 = (年 + 月 + 日) mod 8
下卦 = (年 + 月 + 日 + 时) mod 8
动爻 = (年 + 月 + 日 + 时) mod 6
```

余 0 时卦取 8（坤），爻取 6（上爻）。

- 农历年以正月初一为界：春节前仍属上一年。
- 农历表覆盖农历 1900–2100 年，已与公历逐日（73,384 日）对照无误。
- 时辰：子 23:00–01:00，丑 01:00–03:00 … 亥 21:00–23:00。
  **23:00 起即入子时，归次日**：先把日期推进一天再换农历。

例：2026-10-04 00:35（+08:00）= 丙午年八月廿四子时。
年 7（午）+ 月 8 + 日 24 = 39 → 7 艮上；加时 1 = 40 → 0 作 8 坤下；40 mod 6 = 4 → 山地剥，动六四。

### 时区必须显式传入

```bash
python3 scripts/zy.py cast --at "2026-10-04T00:35:27"        # 拒绝：无时区
python3 scripts/zy.py cast --at "2026-10-04T00:35:27+08:00"  # 正常
```

不带时区则同一时刻在不同时区会算出不同卦，结果不可复现。代码直接拒绝，这是刻意的设计。
时刻按所填墙上时间解读，不做时区换算。

筮竹法需要「随机」分堆，但必须可复现，故用 SHA-256 链式摘要生成确定性整数流：

```python
    # sha256(f"{seed}#{counter}") 逐次取两字节组成整数
```

每个整数决定一次「分而为二」的左手根数（1 … n-1）。
优点：跨平台一致、无需系统随机源、同一 seed 必得同一卦。**不要用随机数代替种子**。

## 爻位命名

| 位置 | 索引 | 阳爻 | 阴爻 |
|---|---|---|---|
| 初爻 | 0 | 初九 | 初六 |
| 二爻 | 1 | 九二 | 六二 |
| 三爻 | 2 | 九三 | 六三 |
| 四爻 | 3 | 九四 | 六四 |
| 五爻 | 4 | 九五 | 六五 |
| 上爻 | 5 | 上九 | 上六 |

`read` 的数字参数是索引（0–5，6 亦指上爻），**1 是二爻而非初爻**。
转述用户说的「第几爻」时用爻题名传参（`read 62 六二`）最稳妥。

乾之用九、坤之用六在 `read` 输出的 `yong` 字段，不属任何一爻。

## 卦象反查

六爻自下而上，1 为阳、0 为阴；下三爻为下卦、上三爻为上卦，以（下卦，上卦）查文王卦序表。
64 种组合一一对应，自检逐一验证，并以独立手录的文王卦序表核对卦名与上下卦。
