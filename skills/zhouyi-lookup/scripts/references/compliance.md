# 合规边界

本文件是本技能的红线说明，不是可选项。

## 为什么必须这么设计

《周易》在性质上是占筮经典，历代注家普遍附带吉凶断语。
如果直接照搬传统占书的表达，几乎必然触碰平台「不得宣扬迷信」的红线。

所以本项目做的不是「把占书搬上网」，而是**把经文、训诂、义理与占断切开**，
只保留前三者，舍弃第四者。

## 明确不做的事

### 1. 不接收占问事项

接口不接受问题文本。

```python
# 不存在这样的接口
POST /divine { "question": "我该不该跟他表白" }
```

**理由**：一旦接收问题文本，接口的语义就是「针对某问题求答案」，
无论返回什么都在做预测。这是结构性的，不是靠改输出措辞能解决的。

高島嘉右衛門在《高島易断》中说：「占卦不是买卖，《易》占不应为了得到某物而占。」
只做结构检索、不给结论，与此一致。

### 2. 不输出自己的吉凶断语

不做：本工具或助手自己的吉凶判断、宜忌指引、具体事项预测。

《増補高島易断》的占断与占例可以**作为引文**输出（`takashima` 命令），
须标明出处，不得改写成对用户事项的结论。

经文里的吉凶字句是**引文**，不是**结论**。
区别在于：

- 引文：「六五：帝乙归妹，以祉，元吉」← 原文照录，标注出处
- 结论：「此爻主大吉，适宜出行」← 禁止

同理，义理层的表述是「泰极而否来，须存防满之心」，
这是对卦义结构的描述，不是对某件事的判断。

### 3. 不承诺准确性

不使用：精准、必中、灵验、应验、保证、100% 准确。

**理由**：这是平台明确列举的「虚假能力声明」红线。
预测类内容的夸大表述是最容易被判定的一条。

### 4. 不导流

包内不得出现：联系方式、外部链接、社交群、二维码。

这是平台治理红线之一，判定后可能下架甚至处置主体资格。

## 自检机制

`tests/test_engine.py` 的 `TestCompliance` 自动扫描全部 64 卦，
检查内容字段（卦辞、爻辞、义理）中是否出现占断用语。

```bash
python3 -m unittest discover -s tests -v   # 在插件根目录运行
# TestCompliance.test_interpretive_layers_have_no_divination_claims ... ok
```

新增或修改数据后必须重跑。检查不通过就不能上架。

`TestTakashimaBook` 另检查高島原文：450 页齐全且与卦爻对齐，
书中占例用略筮法逐条重演，敏感内容默认略去，点校者脚注标记已清除。

注意检查逻辑区分了内容字段与元数据字段：
免责声明里必然出现「不含吉凶预测」这类字眼，是在声明「不含」，
不该被自己的检查拦下。所以只扫内容，不扫免责与出处注记。

## 高岛易断的特殊处理

《高島易断》日文原书（1886 年首版，著者 1914 年卒）作者权已届满，
属公有领域。汉译者王治本（1835–1908）亦早已届满。

v1.2 起收录全书逐卦逐爻原文（`zhouyi/takashima.json`，`takashima` 命令）：

1. **原样引用，标明出处。** 高島的占断是引文，不是本工具的结论。
   输出自带说明：「照录原文，不代表对当下任何具体事项的判断」。

2. **健康与生育默认略去。** 「问疾病」「问六甲」（问胎儿男女）等分事占断，
   以及涉及疾病、分娩的占例，默认不输出。这类事项不应依占断决定。

3. **历史局限。** 该书部分占例为日本对外战争建言、为军国主义行为辩护，
   尤其是中日、日朝关系部分。这些占例（标记 `war`）默认不输出，
   不应作为参考资料传播。`--all` 仅供阅读原书全文时用。

4. **数字化文本的来源。** 所用文本取自网上流传的王治本汉译数字化本，
   该本出自现代点校本（郑同点校，华龄出版社 2017），已删去点校者的脚注标记
   与插图说明，但标点与个别校字仍出自点校者。古籍点校在部分法域可能受保护，
   **用于收费服务前应自行确认**，或改以日文原书（国立国会图书馆数字藏本）重新录入。
